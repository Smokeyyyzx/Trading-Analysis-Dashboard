# Trading-Analysis-Dashboard
A personal trading analysis app that combines live market data with technical indicators such as RSI, MACD, Fibonacci and VWAP. It evaluates multiple strategies, displays LONG, SHORT or WAIT signals, and explains the factors behind each assessment. Built with JavaScript, HTML, CSS and AI-assisted development.

## Features

- Live market data integration
- Analysis of indicators such as RSI, MACD, Fibonacci levels and VWAP
- Combination of multiple strategy signals
- Visual LONG, SHORT and WAIT states
- Explanations showing which signals contribute to the overall assessment

## Technologies

- JavaScript
- HTML
- CSS
- AI-assisted development

## Development process

I planned the application's features and iteratively refined the implementation using AI-assisted coding tools. I tested the results, identified issues and adjusted the application until it better matched the intended functionality.
